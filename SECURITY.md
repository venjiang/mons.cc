# Security reports

Do not disclose a suspected vulnerability, private key, password, access token
or active pairing link in a public issue.

Private vulnerability reporting has not been enabled for this repository yet.
Until a private channel is available, open an issue titled **Request a private
security contact** and include only a request for a private reporting method.
Do not include technical details, exploit steps, attachments or sensitive
identifiers. A maintainer can arrange a private follow-up before you send the
report. If GitHub's **Report a vulnerability** action becomes available on the
repository's Security tab, use that private form instead.

In a private report, describe the affected app/Host version, platform, impact,
reproduction steps and any evidence needed to understand the issue. Do not
send production credentials or another person's data. There is no stated
response-time guarantee while Mons is in development.
